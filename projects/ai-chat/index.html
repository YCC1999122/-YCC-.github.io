def quick_sort(arr, low=0, high=None):
    """
    快速排序算法实现
    时间复杂度: 平均 O(n log n)，最坏 O(n²)
    空间复杂度: O(log n) - 递归栈空间
    """
    if high is None:
        high = len(arr) - 1
    
    if low < high:
        # 获取分区点索引
        pivot_index = partition(arr, low, high)
        # 递归排序左半部分
        quick_sort(arr, low, pivot_index - 1)
        # 递归排序右半部分
        quick_sort(arr, pivot_index + 1, high)
    
    return arr


def partition(arr, low, high):
    """分区函数：选择基准元素并将数组分为两部分"""
    # 选择最后一个元素作为基准
    pivot = arr[high]
    # i 是小于基准的元素的边界
    i = low - 1
    
    for j in range(low, high):
        if arr[j] <= pivot:
            i += 1
            arr[i], arr[j] = arr[j], arr[i]
    
    # 将基准放到正确位置
    arr[i + 1], arr[high] = arr[high], arr[i + 1]
    return i + 1


# 测试示例
arr = [64, 34, 25, 12, 22, 11, 90]
print("排序前:", arr)
print("排序后:", quick_sort(arr.copy()))

很好的问题！快速排序和归并排序都是经典的分治排序算法，但它们有以下关键区别：

1. 排序方式不同
• 快速排序：按值分区，选择一个基准元素，将数组分为「小于基准」和「大于基准」两部分
• 归并排序：按位置分区，将数组从中间分成两半，分别排序后再合并

2. 稳定性
• 快速排序是不稳定的（相等元素的相对顺序可能改变）
• 归并排序是稳定的

3. 空间复杂度
• 快速排序：O(log n) 递归栈空间，原地排序
• 归并排序：O(n) 额外空间用于合并

4. 适用场景
• 快速排序适合内存排序、数组排序，实际运行速度通常更快
• 归并排序适合链表排序、外部排序（大数据量磁盘排序）、需要稳定性的场景

在实际应用中，大多数语言的内置排序（如 Python 的 list.sort()）使用的是 TimSort，一种结合了归并排序和插入排序优点的混合算法。
