Game Intro

游戏介绍

1
玩法

高速忍者跑酷，核心机制是"时间减速"——按住右键时间减速到 10%，可以精准规划路线、躲避子弹、斩击多个敌人。松开后时间恢复，按规划的路线瞬间执行。

2
特色

墙壁反弹跑酷、瞬移斩击、子弹反弹格挡。整个都市是一个开放的垂直关卡，从底层到顶层霓虹天际。

3
创新点

时间减速不是慢动作，而是"规划-执行"模式。减速时规划路线，恢复时以电影级速度瞬间完成。
